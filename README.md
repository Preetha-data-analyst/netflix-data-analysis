# Netflix Data Analytics Dashboard

Power BI dashboard project exploring Netflix title metadata across content type, ratings, genres, countries and release years.

## Dataset
The supplied CSV contains:
- 8,807 records
- 12 columns
- 6,131 Movies
- 2,676 TV Shows
- release years from 1925 to 2021

## Tools
- Power BI
- Power Query
- Data Visualization

## Dashboard
The dashboard includes:
- headline KPIs;
- ratings by total shows;
- genres by total shows;
- a country map;
- Movie vs TV Show composition;
- total shows by release year.

## Data-backed observations
From the supplied CSV:
- Movies represent 69.62% of records and TV Shows 30.38%.
- There are 17 non-null rating categories; including blank rating values gives 18 distinct values.
- `listed_in` contains 514 distinct genre strings.
- `country` contains 748 distinct non-null country strings.

The dashboard itself displays KPIs including total shows, total ratings, genres, directors and date range.
